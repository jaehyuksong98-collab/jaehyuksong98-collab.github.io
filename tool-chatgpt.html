The role I would give it

I would use ChatGPT to turn a financial question into a clear work plan, help write Python, and build a first version of a model. I would start with one company and a small set of public filings.

How I would guide it

I would specify the company, reporting period, currency, units, and decision the model needs to support. Every extracted figure should come with a source and page number. Missing values should stay missing until I can resolve them.

What I would check

I would trace important inputs back to the filing, reconcile totals, run the code, and test changes in assumptions. A clean spreadsheet or a convincing explanation is not enough.

A useful next test

I would compare GPT-6 Astra and Claude Opus 5.5 on the same source pack. I would record wrong figures, broken formulas, unsupported claims, review time, and cost before choosing a routine.
